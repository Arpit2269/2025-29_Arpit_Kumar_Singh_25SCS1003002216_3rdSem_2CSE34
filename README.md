# NetSage AI – Applied AI for Network Troubleshooting

## About the Project

**NetSage AI** is an AI-assisted network troubleshooting application developed as part of the **Cisco–AICTE Virtual Internship Program**.

The project is designed to help identify and understand common network issues using a combination of **AI-assisted diagnosis, network evidence, deterministic rule checking, and human review**.

The system covers practical troubleshooting scenarios related to:

- VLAN
- Routing
- Gateway
- DHCP
- DNS
- ACL
- NAT
- Wireless

The application follows an evidence-based workflow:

**Network Problem → Evidence → AI Diagnosis → Rule Verification → Human Review → Troubleshooting Guidance**

A key focus of the project is **Responsible AI**. The system does not blindly apply network changes. AI recommendations are presented for verification, and human review is used before any corrective action is considered.

---

## Project Features

- Interactive troubleshooting case browser
- AI-assisted root-cause diagnosis
- Evidence-based explanations
- Confidence and OSI-layer information
- Deterministic network rule checker
- Suggested verification commands
- Troubleshooting and remediation steps
- Human review with Accept / Edit / Reject outcomes
- Diagnosis and review history
- Dashboard for case and review statistics
- Validation tools for checking project consistency
