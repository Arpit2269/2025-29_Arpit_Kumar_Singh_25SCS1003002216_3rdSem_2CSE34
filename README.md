# NetSage AI – Applied AI for Network Troubleshooting

## About the Project

NetSage AI is an AI-assisted network troubleshooting application developed as part of the **Cisco–AICTE Virtual Internship Program**.

The project is designed to assist in identifying and understanding common network problems by combining network evidence, AI-assisted diagnosis, deterministic rule checking, and human review.

The troubleshooting cases cover major networking areas including:

- VLAN
- Routing
- Gateway
- DHCP
- DNS
- ACL
- NAT
- Wireless

The overall workflow is:

**Network Problem → Evidence → AI Diagnosis → Rule Verification → Human Review → Troubleshooting Guidance**

A key focus of the project is responsible and evidence-based use of AI. The system presents recommendations for verification rather than treating an AI prediction as an automatic network configuration change.

---

## Key Features

- Interactive network troubleshooting case browser
- AI-assisted root-cause diagnosis
- Evidence-based diagnostic explanations
- Confidence and OSI-layer information
- Deterministic rule-based network analysis
- Recommended commands for diagnosis verification
- Troubleshooting and remediation guidance
- Human review with Accept / Edit / Reject outcomes
- Diagnosis and review history
- Dashboard with project and review statistics
- Submission validation and consistency checks
